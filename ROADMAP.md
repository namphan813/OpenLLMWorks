# OpenLLMBench Roadmap

The roadmap describes the long-term evolution of OpenLLMBench.

Each phase builds upon the previous one while remaining aligned with the project's mission:

> **Measure. Understand. Preserve.**

OpenLLMBench is intentionally built in phases.

Each phase establishes a stable foundation before introducing the next major capability.

The goal is steady, sustainable progress rather than rapid feature accumulation.

---

# ✅ Foundation

**Status:** Complete

Established the technical foundation of OpenLLMBench.

### Highlights

- Benchmark parser
- Persistent benchmark database
- Deterministic result IDs
- Duplicate detection
- Core statistics engine

### Outcome

OpenLLMBench became capable of reliably collecting and storing benchmark data.

# Future Ideas

Ideas that are intentionally outside the current roadmap are tracked separately in:

```
docs/PARKING_LOT.md
```

This allows OpenLLMBench to capture inspiration without creating feature creep.

---

# Guiding Principle

Every future feature should strengthen one or more of these goals:

```
Measure
    ↓
Understand
    ↓
Preserve
```

When evaluating a new idea, ask:

- Does it help users measure local AI performance?
- Does it help users understand benchmark data?
- Does it help preserve benchmark history?

If the answer is **yes**, it likely belongs in OpenLLMBench.

---

*"Software changes. Hardware changes. History remains."*

**Measure. Understand. Preserve.**
