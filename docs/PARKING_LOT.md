# OpenLLMWorks Parking Lot

The Parking Lot is a collection of ideas that are intentionally **not** part of the current sprint.

Its purpose is simple:

Capture inspiration without interrupting momentum.

Ideas belong here until they are promoted into the roadmap.

---

# How We Use This Document

When a new idea appears:

1. Write it down.
2. Give it a short description.
3. Explain why it might be valuable.
4. Don't build it immediately.
5. Continue the current sprint.

This allows us to preserve good ideas without creating feature creep.

# Promotion Rules

An idea graduates from the Parking Lot only when:

- it aligns with the project mission;
- current priorities are complete;
- it has a clear user benefit;
- the maintenance cost is understood.

Ideas are never promoted simply because they are interesting.
