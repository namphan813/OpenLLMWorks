# OpenLLMWorks Development Guidelines

## Philosophy

The project favors readability, maintainability, and incremental progress over rapid feature development.

---

## React

- Prefer reusable components.
- Avoid duplicated styling.
- Keep components focused on one responsibility.
- Build generic UI before page-specific implementations.

---

## Git

Every completed feature should follow:

1. Build
2. Test
3. Commit
4. Push

Commit messages should describe completed work.

Examples:

- Add homepage footer component
- Add hardware profile page
- Improve leaderboard layout

---

## Documentation

Documentation is updated before or alongside implementation.

Important documents include:

- ROADMAP.md
- STATUS.md
- PARKING_LOT.md

---

## Design

The website should feel:

- Professional
- Fast
- Welcoming
- Data-first
- Community-driven

Avoid unnecessary animations or visual clutter.

---

## Mission

Measure.

Understand.

Preserve.
